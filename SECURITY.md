# Security Policy

## Supported versions

Only the `main` branch is supported. It is what runs at [nixoncreativestudio.com](https://nixoncreativestudio.com).

## Reporting a vulnerability

Please report security issues privately by email to **nathan@nixoncreativestudio.com**. Do not open a public issue or pull request for a vulnerability.

Include what you found, where you found it, and the steps to reproduce it. I will reply as soon as I can and keep you posted until it is fixed. Please give me a reasonable chance to fix the issue before sharing it more widely.
