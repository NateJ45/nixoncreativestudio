Installing in Gmail

  1. Press a Copy button above.
  2. In Gmail: Settings, See all settings, General, Signature. Pick the signature (or Create new), click in the box, select all and paste.
  3. Under Signature defaults, set the full one for new emails and the compact one for replies and forwards. Save changes at the bottom of the page.
